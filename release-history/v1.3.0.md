# Google Flow Scripting Skill v1.3.0

Release date: 2026-07-23

## Validator

- Preserved raw beat order and duplicate intervals instead of normalising them away.
- Rejected out-of-order and duplicated beat lines with targeted diagnostics.
- Required the text policy to be the first semantic line of every prompt.
- Accepted explicit intentional-text policies as an alternative to blanket no-text instructions.
- Added `--no-require-audio` while keeping audio checks enabled by default.
- Treated `AUDIO: Intentional silence.` as a valid deliberate choice.
- Emitted pure machine-readable JSON with settings and disabled-check metadata.
- Expanded hex-colour detection to common 3-, 4-, 6-, and 8-digit forms.

## Packaging and installation

- Added a canonical root `SKILL.md` package.
- Installed native Skills to Claude Code, Cursor, and Windsurf Skill directories.
- Kept Claude specialist subagents as an optional `--install-subagents` add-on.
- Staged installations atomically and created timestamped backups before replacement.
- Added `--target` for explicit destination control.
- Resolved the `formats` division dependency on core resources.

## Tests and documentation

- Added regression fixtures for timing, text policy, multiple segments, audio policy, and installer behaviour.
- Replaced absolute memory claims with the more accurate phrase "no guaranteed implicit memory."
- Clarified that pacing, text, and audio requirements are project policies rather than universal creative laws.
