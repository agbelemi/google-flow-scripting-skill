# Google Flow Scripting Skill v1.5.0

Release date: 2026-07-23

## Storyboard contract

- Hard-coded the storyboard-generation rule in the storyboard director.
- Required every copy-paste storyboard prompt to begin with `GENERATE THE STORYBOARD IMAGE NOW.`
- Required exact panel count and layout, prohibited planning responses, and prohibited invented actions.
- Set four panels in a 2x2 grid as the default for a ten-second scene with four authored states.
- Allowed 3x3 only when nine distinct frames were explicitly authored.
- Separated operator notes, image-generation prompts, and human approval checklists.

## Reference handles and punctuation

- Required every character and location reference to use a canonical `@PascalCase` handle with no spaces or punctuation.
- Added validator checks for missing `@` prefixes, spaces in handles, and bare reuse of declared reference names.
- Removed em dashes from the package and added repository-wide and per-script checks that prevent them from returning.

## Model accuracy and validator behaviour

- Split Flow and Gemini API capability profiles.
- Corrected Flow Omni durations to 4, 6, 8, and 10 seconds.
- Recorded the Veo 3.1 API 1,024-token text-input limit and Omni's larger multimodal context window.
- Added surface and model arguments, flexible beat modes, and a Veo prompt-length estimate.
- Removed the false claim that three image references is a universal Omni ceiling.

## Automation

- Added `.github/workflows/tests.yml`.
- Expanded regression, integration, installer, model, storyboard, handle, and package-integrity coverage to 40 passing checks.
