# Google Flow Scripting Skill v1.6.0

Release date: 2026-07-24

## Safe installation and updating

- Added a cross-platform Python installer with Bash and PowerShell launchers.
- Added `VERSION` as the single package version source.
- Added `scripts/check_update.py` for explicit, non-silent update checks.
- Added `scripts/update.py` for checksum-verified, tested, backed-up release updates.
- Added local-modification detection through `.installed-manifest.json`.
- Added backup retention controls and restart guidance after updates.
- Prevented the release updater from replacing Git working trees by default.

## Release engineering

- Added `scripts/build_release.py` to build versioned ZIP and tar.gz assets, `MANIFEST.json`, and `SHA256SUMS`.
- Added `scripts/verify_package.py` for version, manifest, changelog, release-record, and punctuation integrity.
- Added a tag-driven GitHub release workflow that runs tests, builds assets, verifies the tag, and publishes immutable versioned downloads.
- Added a release-history directory with one permanent record per version and a machine-readable index.
- Added repository issue templates, a pull-request template, security guidance, support guidance, and Dependabot configuration for GitHub Actions.

## Storyboard generation

- Added a canonical storyboard contact-sheet template.
- Added `scripts/generate_storyboard_prompt.py`, which creates separated operator notes, a copy-paste image prompt, and an approval checklist from JSON.
- Added an executable ten-second 2x2 storyboard example using canonical `@ReferenceHandles`.
- Expanded storyboard validation to require actual panel sections in the declared order.

## Validator and documentation

- Added a generation-mode argument and surface, model, mode, and duration compatibility checks.
- Corrected stale model and feature claims in the skill, playbook, capability matrix, examples, and failure table.
- Added update, versioning, migration, and release-process documentation.
- Expanded automated checks for update safety, release archives, changelog history, version consistency, generator output, and GitHub workflows.
