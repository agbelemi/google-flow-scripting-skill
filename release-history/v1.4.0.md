# Google Flow Scripting Skill v1.4.0

Release date: 2026-07-23

## Historical correction note

Added in v1.5.0 and retained here for accuracy: v1.4.0 correctly added support for ten-second Omni clips, but two accompanying statements were too broad. Omni Flash also supports 4-, 6-, and 8-second generations in Flow, and the Veo 3.1 API publishes a 1,024-token text-input limit. The corrected capability model is recorded in v1.5.0 and later.

## Changes made in this release

- Added ten-second segment support and allowed `--segment-length 10`.
- Fixed Markdown segment headings such as `# SEGMENT 1`.
- Made surface, model, and segment duration mandatory intake decisions before scene writing.
- Restated the storyboard gate as unconditional.
- Added the rule to build reference plates from approved images rather than identity prose.
- Reordered asset planning into cast, environments, and per-segment allocation.
- Added model-first planning and prompt-attention guidance.
- Raised the test suite to 26 checks.
